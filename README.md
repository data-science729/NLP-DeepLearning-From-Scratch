## 📝 平时练习的小原则

自己写代码时，尽量提醒自己注意以下几点：
1. **多思考张量形状（Shape）**：每次矩阵相乘前，先在注释里标清楚维度变换，避免全靠玄学 Debug。
2. **尽量少写无意义的 for 循环**：能用矩阵乘法、张量广播或者掩码解决的地方，尽量练习向量化写法。
3. **注意数值稳定性**：比如写 Softmax 时记得减去最大值防上溢，除法时加微小量防除零。
4. **每写一个模块都配上小测试**：用简单的数据手算预期结果，写上 `assert` 验证，确保逻辑确实跑通。
