> 本仓库是作者大三上学期学习人工智能时所设立的 包括的主题有 ML DL RL NLP LLM 凸优化 和数据处理

---

### 1. ML部分
主要学习的无监督学习部分

### 2. DL部分
主要根据邱锡鹏的《神经网络与深度学习教材》与《动手学深度学习》和包括前馈神经网络 CNN RNN LSTM Transformer的整套学习 网络优化和正则化相关内容，做好Deep-ml上的一些基础题目

### 3. RL部分
这部分主要根据《动手学强化学习》教材的基础篇，主要包括了MDP,RL中的DP算法，TD算法和Q-learning算法 仓库中做了CS188 Project3的项目实现，该项目通过手写马尔可夫决策过程（MDP）与 Q-Learning 算法，让 Pacman 游戏角色和关节机器人从零开始学会自主决策与运动控制。

### 4. NLP部分
主要根据张奇《自然语言处理》，紧跟学校进度 

### 5. LLM部分
这部分比较先进 主要是在NLP基础上 学一些算法，比如BPE字节对编码这些基本算法，属于现代的NLP，正如张奇教材中所说自然语言处理基本范式最新的是"基于大模型的方法"，这块可能对"天赋"要求比较高，因此也是打一点基础，不去很深探究。

### 6. 凸优化部分
用的是北大的教材 这部分的话是应用数学和计算机的交叉学科 打好数学基础 同时写好凸优化的一些代码 算法

### 7. 数据处理部分
这部分是大二的知识 但当时基础没打好(不会写代码) 在这个仓库里主要根据本学期学的数据可视化相关内容来精进，做好力扣上的pandas 30题
