# 束搜索（Beam Search）解码算法深度解析与手撕指南

> **核心定位**：自然语言生成（GPT、Seq2Seq、机器翻译、语音识别等）自回归解码阶段最核心的搜索算法。
> **本质定性**：带宽度剪枝的广度优先搜索（Pruned BFS），是“贪心搜索（Greedy）”与“暴力全搜索（Exhaustive Search）”之间的启发式折中。

---

## 一、为什么大模型需要束搜索？

自回归语言模型在生成文本时，每一步模型输出当前词表大小为 $V$ 的得分向量（Logits），目标是找到联合概率最大的整句话：
$$Y^* = \arg\max \prod_{t=1}^T P(y_t \mid y_{1:t-1}) = \arg\max \sum_{t=1}^T \log P(y_t \mid y_{1:t-1})$$

面对这个图搜索问题，计算机有两种极端策略：
1. **极端 1：暴力穷举搜索（Exhaustive Search）**
   - 展开所有可能：搜索树大小为 $V^T$。若词表 $V=30000$，句子长度 $T=20$，状态数为 $30000^{20}$，算力爆炸，无法计算。
2. **极端 2：贪心搜索（Greedy Search）**
   - 每步只选当前概率最大的词（$K=1$）。
   - **致命缺陷：目光短浅**。第 1 步选了局部概率 0.6 的词，可能导致后续全是 0.01；而第 1 步选概率 0.4 的词，后面跟着全是 0.9。贪心会错失全局更优的句子。
3. **明智的折中：束搜索（Beam Search）**
   - 设定束宽（Beam Width，记为 $K$）。
   - 每一层搜索时，**永远只保留当前全局综合得分最高的 $K$ 个候选序列（称为 $K$ 个“束”，Beams）**，将其余较差的分支全部剪枝丢弃。
   - 复杂度从指数级 $O(V^T)$ 直降到多项式级 $O(T \cdot K \cdot V)$！

---

## 二、核心数学公式（李航《统计学习方法》规范表述）

### 算法（带长度惩罚与终止符的束搜索解码算法）

**输入**：
- 逐步得分向量序列 $Z = (z_1, z_2, \dots, z_T)$，其中 $z_t \in \mathbb{R}^V$ 为第 $t$ 步在词表 $\mathcal{V} = \{0, 1, \dots, V-1\}$ 上的原始打分向量（Logits）；
- 束宽（Beam Width）$K$；
- 长度惩罚系数 $\alpha \ge 0$；
- 终止符编号 $\text{eos\_id} \in \mathcal{V}$（可选，若无则为 $\text{None}$）。

**输出**：
- 最优输出序列 $y^* = (y_1^*, y_2^*, \dots, y_{L^*}^*)$。

---

#### (1) 初始化
设定初始时刻 $t=0$ 的候选束集合 $\mathcal{B}_0$，仅包含一个空序列 $\emptyset$，其累积对数概率为 $0$：
$$\mathcal{B}_0 = \{ (s^{(1)}, c^{(1)}) \} = \{ (\emptyset, 0.0) \}$$
其中每个候选元素为二元组 $(s, c)$，$s$ 表示已生成的 token 序列，$c$ 表示累积对数概率。

---

#### (2) 递推
对时间步 $t = 1, 2, \dots, T$：

##### ① 计算当前步条件对数概率
对打分向量 $z_t$，计算词表中各词的归一化条件概率分布 $p_t$ 及其对数概率 $\text{lp}_t$：
$$p_t(v) = \frac{\exp(z_{t, v})}{\sum_{j=0}^{V-1} \exp(z_{t, j})}, \quad v \in \mathcal{V}$$
$$\text{lp}_t(v) = \ln(p_t(v) + \epsilon), \quad v \in \mathcal{V}$$
式中 $\epsilon$ 为防止下溢设置的极小正数（取 $10^{-12}$）。

##### ② 候选集合全量扩展
由上一时刻集合 $\mathcal{B}_{t-1}$ 扩展生成当前时刻的临时候选全集 $\mathcal{C}_t$。对于 $\mathcal{B}_{t-1}$ 中的每一个候选束 $(s, c)$：
- **若该束已结束**（$\text{eos\_id} \ne \text{None}$ 且末尾元素 $s_{|s|} = \text{eos\_id}$）：
  不再向后拼接新词，原样保留：
  $$\mathcal{C}_t \leftarrow \mathcal{C}_t \cup \{ (s, c) \}$$
- **若该束未结束**：
  遍历词表 $\mathcal{V}$ 中的每一个词 $v$，拼接得到新序列并累加对数概率：
  $$\mathcal{C}_t \leftarrow \mathcal{C}_t \cup \{ (s \circ [v], \, c + \text{lp}_t(v)) \}$$

##### ③ 长度惩罚评分
对 $\mathcal{C}_t$ 中的每一个候选束 $(s, c)$，计算其长度惩罚综合得分：
$$\text{score}(s, c) = \frac{c}{(\max(|s|, 1))^\alpha}$$

> **长度惩罚的物理意义（高频考点）**：
> 因为概率 $p \le 1 \implies \log p \le 0$。句子越长，负数累加越多，总分越低。
> 若不做惩罚，模型会严重倾向于只输出一两个词就早早结束。
> 分母除以 $L^\alpha$ 后，负数分子除以大于 1 的底数使绝对值变小（即负得更少，综合得分更高），拉平长句子的劣势，鼓励生成完整长句。

##### ④ 剪枝截断（Top-$K$ 筛选）
将 $\mathcal{C}_t$ 中候选按 $\text{score}(s, c)$ 降序排列；若并列则按序列 $s$ 的字典序升序排列。截取前 $K$ 个最优候选更新保留集合：
$$\mathcal{B}_t = \underset{(s, c) \in \mathcal{C}_t}{\text{arg top-}K} \, \text{score}(s, c)$$
在进入下一轮前，候选状态恢复为序列与原始累积对数分二元组：$\mathcal{B}_t \leftarrow \{ (s, c) \mid (s, c) \in \mathcal{B}_t \}$。

---

#### (3) 终止
当 $t = T$ 时，递推循环结束，保留最终候选集 $\mathcal{B}_T$。

#### (4) 求最优路径
从 $\mathcal{B}_T$ 中选取经长度惩罚后综合得分最高者作为最终输出序列：
$$y^* = \underset{(s, c) \in \mathcal{B}_T}{\arg\max} \, \text{score}(s, c)$$

## 三、高频语法与关键工程细节拆解（面试/考研避坑宝典）

### 1. `from typing import Optional` 与渐进式类型
- **本质**：`typing` 是 Python 3.5 引入的官方**类型注解标准库**，专供程序员阅读与 PyCharm 等 IDE 做代码补全、静态分析，**在运行时解释器不会强行拦截报错**。
- **`Optional[int] = None`**：表示该参数既可以是一个整数（如 `2`），也可以为空（`None`）。底层等价于 `Union[int, None]`。
- **C++ 对比**：完全等价于 C++17 的 `std::optional<int>` 或传指针 `int* = nullptr`。
- **现代写法**：Python 3.10+ 原生支持写成 `int | None = None`，无需从 `typing` 导入。

---

### 2. `torch.softmax(logits_t, dim=-1)` 的 `dim` 维度剖析
- **黄金法则**：`dim` 指定哪一维，哪一维上的元素加起来严格等于 1。
- **为什么统一写 `dim=-1`？**
  - 一维向量 `(V,)`：`dim=0` 和 `dim=-1` 等价，跨词表归一化。
  - 二维矩阵 `(Batch, V)`：`dim=-1` 表示对每一行（每个样本）跨列类别归一化。
  - 三维张量 `(Batch, Seq_len, Vocab_size)`：`dim=-1` 表示对每个时间步跨整张词表归一化。
  - **结论**：最后一维永远是词表/类别维度，写 `dim=-1` 是具备极强通用性的工业肌肉记忆。

---

### 3. `for seq, cum_lp in beams:` 自动解包机制
- `beams` 是列表套元组：`[ (seq, cum_lp), ... ]`。
- 循环遍历时，Python 会自动把内层元组拆开分别赋值给两个变量。
- **C++ 对比**：等价于 C++17 的结构化绑定 `for (auto [seq, cum_lp] : beams)`。

---

### 4. `new_seq = seq + [v]` 与 `lp[v].item()`
#### ① 为什么是 `seq + [v]` 而绝不能用 `seq.append(v)`？
- `seq.append(v)` 是**原地修改（In-place）**。若在 `for v in range(V):` 循环里使用，前一个分支追加的词会残留在 `seq` 中，导致各个并行分支互相污染崩溃！
- `new_seq = seq + [v]` 利用列表加法拼接，**安全克隆并生成一个全新的独立列表**，原 `seq` 完好无损，供下一个分支继续使用。
- 必须用 `[v]` 包裹是因为 Python 中列表只能与列表相加，不能直接加整数。

#### ② 为什么必须加 `.item()`？
- `lp[v]` 取出后依然是一个 PyTorch 的 0 维 Tensor。
- `.item()` 的作用是：**脱掉 Tensor 外壳，提取为纯 Python `float` 数字**。
- **避免显存泄漏**：如果不脱壳，累加时 PyTorch 会不断挂载计算图节点，占用显存和内存导致 OOM。转为原生浮点数后轻量且无依赖。

---

### 5. 三重守卫安检门：`if eos_id is not None and len(seq) > 0 and seq[-1] == eos_id:`
- **短路求值原则（Short-Circuit Evaluation）**：Python 从左往右执行 `and`。
- **顺序铁律**：`len(seq) > 0` **必须死死排在 `seq[-1]` 的前面！**
  - 开局时 `seq = []`，若先执行 `[][-1]` 会当场报 `IndexError: list index out of range` 崩溃。
  - 前面有了 `len(seq) > 0` 判定为假，后面的 `seq[-1]` 根本不会被触发。
- `eos_id is not None` 是总开关，如果未启用结束符，跳过后续全部检查。

---

### 6. `candidates` 为什么是三元组？`beams` 为什么是二元组？
- **`candidates = [(seq, cum_lp, score), ...]`（三元组）**：
  - 作为“比武招亲现场”，每个候选必须带着算好的长度惩罚分 `score`，供紧随其后的排序函数决定排名。
- **`beams = [(seq, cum_lp), ...]`（二元组）**：
  - 截取前 $K$ 名后，`score` 的历史使命完成，因为下一轮步数增加后该分值即作废。
  - 只保留 `seq`（句子）和 `cum_lp`（原始累加器，供后续步骤继续加分）。

---

### 7. 双关键字排序规则与 `get_sort_key`
```python
def get_sort_key(candidate):
    seq = candidate[0]    # 句子列表
    score = candidate[2]  # 惩罚后得分
    return (-score, seq)  # 负分数排前面（降序），句子字典序小的排前面（升序）
```
- **负号技巧**：Python 默认升序，给分数加上负号 `-score` 即可实现分数降序。
- **平局决胜**：第一关键字 `-score` 相同（打平）时，Python 会自动比较元组第二项 `seq` 列表的字典序，实现升序排列。

#### C++ 对应结构体实现（机试极力推荐）：
```cpp
struct Candidate {
    vector<int> seq;
    float cum_lp;
    float score;

    bool operator<(const Candidate& other) const {
        if (score != other.score) return score > other.score; // 降序
        return seq < other.seq;                               // 字典序升序
    }
};
vector<Candidate> candidates;
sort(candidates.begin(), candidates.end());
```

---

### 8. `return beams[0][0]` 的分层解包访问
- `beams`：装满前 $K$ 名的列表。
- `beams[0]`：取出排在第 1 名的包裹元组 `([0, 2, 1, 0], -1.45)`。
- `beams[0][0]`：取出该包裹内的第 0 项，即纯句子列表 `[0, 2, 1, 0]`，满足题目返回值要求。
- （若要访问第 1 名的分数，用 `beams[0][1]`；访问第 2 名的句子，用 `beams[1][0]`）。

## 四、完整工程实现（100% 验证通过的黄金模板）

```python
import torch
from typing import Optional

def get_sort_key(candidate):
    seq = candidate[0]    # 拿到句子
    score = candidate[2]  # 拿到惩罚得分
    return (-score, seq)  # 负分降序，序列字典序升序

def beam_search_decode(
    logits_steps: torch.Tensor,
    beam_width: int,
    length_penalty: float = 1.0,
    eos_id: Optional[int] = None,
) -> list[int]:
    """
    基于 PyTorch 实现的束搜索解码算法
    :param logits_steps: 形状为 (T, V) 的二维张量，T 为时间步数，V 为词表大小
    :param beam_width: 束宽 K (每步保留的候选数)
    :param length_penalty: 长度惩罚系数 alpha
    :param eos_id: 结束符 Token ID (可选)
    :return: 综合得分最优的 Token 序列 list[int]
    """
    # 1. 获取规模尺寸
    T, V = logits_steps.shape

    # 2. 初始化容器：(当前序列, 原始累积对数分)
    beams = [([], 0.0)]

    # 3. 按步推进解码
    for t in range(T):
        logits_t = logits_steps[t]
        p = torch.softmax(logits_t, dim=-1)
        lp = torch.log(p + 1e-12)
        candidates = []

        # 遍历上一轮留下的每一个束
        for seq, cum_lp in beams:
            # 分支 A：若已遇到结束符，冻结不再延伸
            if eos_id is not None and len(seq) > 0 and seq[-1] == eos_id:
                L = max(len(seq), 1)
                score = cum_lp / (L ** length_penalty)
                candidates.append((seq, cum_lp, score))
            # 分支 B：未结束，扩展词表中所有分支
            else:
                for v in range(V):
                    new_seq = seq + [v]
                    new_cum_lp = cum_lp + lp[v].item()
                    L = max(len(new_seq), 1)
                    score = new_cum_lp / (L ** length_penalty)
                    candidates.append((new_seq, new_cum_lp, score))

        # 4. 全局排序截断
        candidates.sort(key=get_sort_key)
        new_beams = []
        for i in range(min(beam_width, len(candidates))):
            cand = candidates[i]
            new_beams.append((cand[0], cand[1]))
        
        # 5. 换届交接
        beams = new_beams

    # 6. 大循环结束，返回冠军序列
    return beams[0][0]


if __name__ == "__main__":
    torch.manual_seed(42)
    # 模拟 4 步，词表大小为 5
    sample_logits = torch.randn(4, 5)

    # 测试 1：常规无 EOS
    res1 = beam_search_decode(sample_logits, beam_width=3, length_penalty=1.0)
    print("最优序列 (无 EOS):", res1)

    # 测试 2：带 EOS=2 冻结机制
    res2 = beam_search_decode(sample_logits, beam_width=3, length_penalty=1.0, eos_id=2)
    print("最优序列 (设 EOS=2):", res2)
```
