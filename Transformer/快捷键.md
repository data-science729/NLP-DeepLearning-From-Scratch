# 🚀 Jupyter Notebook / PyCharm 常用快捷键速查表

> 💡 **提示**：在 Notebook 中，按 `Esc` 进入**命令模式**（蓝色框），按 `Enter` 进入**编辑模式**（绿色框/光标闪烁）。

---

### 一、 运行与执行（核心最常用）

| 快捷键 | 功能说明 | 推荐场景 |
| :--- | :--- | :--- |
| **`Shift + Enter`** | 运行当前单元格，并**跳转到下一个**单元格 | 顺次逐块跑代码 |
| **`Ctrl + Enter`** | 运行当前单元格，**停留在当前**单元格 | 反复调试某一块代码 |
| **`Alt + Enter`** | 运行当前单元格，并在**下方插入新单元格** | 边写边拓展新逻辑 |

---

### 二、 单元格创建、删除与管理（需先按 `Esc` 进入命令模式）

| 快捷键 | 功能说明 | 记忆方法 |
| :--- | :--- | :--- |
| **`A`** | 在当前单元格 **上方** 插入新单元格 | **A**bove |
| **`B`** | 在当前单元格 **下方** 插入新单元格 | **B**elow |
| **`D` + `D`** *(连按两次D)* | **删除** 当前单元格 | **D**elete |
| **`Z`** | **撤销** 上一次的删除操作 | Undo（救命快捷键） |
| **`C`** | 复制当前单元格 | Copy |
| **`V`** | 粘贴当前单元格到下方 | Paste |
| **`X`** | 剪切当前单元格 | Cut |

---

### 三、 模式与格式转换（需先按 `Esc` 进入命令模式）

| 快捷键 | 功能说明 |
| :--- | :--- |
| **`M`** | 将当前单元格转换为 **Markdown（笔记）** 模式 |
| **`Y`** | 将当前单元格转换为 **Code（代码）** 模式 |
| **`1` ~ `6`** | 快速生成 **1~6 级标题**（例：按 `1` 自动变 `# 标题`） |

---

### 四、 代码编写与调试辅助

| 快捷键 | 功能说明 |
| :--- | :--- |
| **`Ctrl + /`** | 快速批量**注释 / 取消注释**代码 |
| **`Tab`** | 自动补全代码 / 增加缩进 |
| **`Shift + Tab`** | 查看函数的**文档说明与参数**（调 PyTorch API 必用） |
| **`Ctrl + 点击函数`** | 追溯并跳转到该函数/类的**底层源码** |

---

### 📝 常用 Markdown 常用小语法

- **标题**：`# 一级标题` 、 `## 二级标题` 、 `### 三级标题`
- **强调**：`**加粗文本**` 、 `*斜体文本*` 、 `` `单行代码` ``
- **数学公式（LaTeX）**：
  - 行内公式：`$Q \cdot K^T$`
  - 独立公式块：
    $$
    \text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V
    $$
