### 1.2 数据清洗问题与处理方法回答（点击右上角复制）：
```text
看了一下数据和和鲸上的项目，里面确实有不少需要清洗的地方。

主要有下面这几种情况和处理方法：
1. 重复数据：有的岗位信息抓取重复了，内容一模一样。可以用 df.duplicated() 查一下，然后直接用 df.drop_duplicates() 把多余的重复行去掉。
2. 缺失值：有些列空缺比较多，比如 positionHighlight（职位亮点）有80%多都是空的，这种留着没啥意义可以直接 drop 删掉整列；像融资情况、所在区域、公司介绍这种分类文本，可以 fillna 填成 "未知" 或者 "未公开"；如果是关键信息（比如工作经验要求）缺失很少，可以直接 dropna 删掉那几行。
3. 文本太乱：
   - skillLabel 和 welfareLabel 里面好几个技能或福利挤在一个单元格里，中间用空格逗号混着隔开，需要用 str.split() 拆开，再用 explode() 展开成单独一行一个词，顺便用 strip() 和 lower() 把多余空格去掉、大写转小写。
   - jobDesc 岗位描述里面带有很多像 <p>、<br>、<div> 这种 html 标签，需要用正则表达式把标签过滤掉，只保留里面的纯汉字和英文。
4. 薪资不是纯数值：salaryReal 写的是 "15001-18000" 这种区间文本，没法直接算平均数，需要把最低薪资和最高薪资拆出来转成 float 算个均值；而且有的按月算有的按天算，需要根据 salaryType 统一折算一下。
5. 无效列：看了一下 futureJob 那一列，里面每一个数据全都是 False，方差为0没啥分析价值，直接用 df.drop() 把整列删了就行.
```

## 9. (简答题, 10分) 第8题使用的python代码

### 答题区代码（点击右上角复制）：
```python
skill_df = df.copy()

# 按空白字符拆分（空格、制表符等），也支持逗号、斜杠等
skill_df['skill'] = skill_df['skillLabel'].astype(str).str.split(r'[,\s/、;；]+')
# 展开成一行一个技能
skill_df = skill_df.explode('skill')
# 清理：去空格、转小写、去空字符串
skill_df['skill'] = skill_df['skill'].str.strip().str.lower()
skill_df = skill_df[skill_df['skill'] != '']
# 把空值转字符串出来的 'nan' 过滤掉
skill_df = skill_df[skill_df['skill'] != 'nan']

# 统计每个技能出现的次数
skill_counts = skill_df['skill'].value_counts()

# 计算每种技能出现的频率（出现次数 / 总行数）
skill_freq = pd.DataFrame({
    "出现次数": skill_counts,
    "出现频率(占总职位数)": (skill_counts / len(df)).map(lambda x: f"{x:.4f} ({x*100:.2f}%)")
})

# 看一下排名前20的技能
print(skill_freq.head(20))
```
